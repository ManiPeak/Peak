# ⛰️ Peak — دستیار هوش مصنوعی شخصی

**همه‌چیز در یک برنامه — روی کامپیوتر خودت، بدون ابر.**

Peak یک دستیار هوش مصنوعی کامل ویندوز است: باهاش **چت** می‌کنی، **حرف** می‌زنی، **یادش می‌ماند**، و حتی **ماینکرفت بازی** می‌کند. همه‌چیز محلی (Local-First) اجرا می‌شود و داده‌هایت فقط روی سیستم خودت می‌ماند.

---

## ✨ قابلیت‌ها

### 🗨️ چت و گفتگو
- گفتگوی فارسی/فینگیلیش با هوش مصنوعی (مدل داخلی رایگان + اتصال به ChatGPT، Gemini، Claude و...)
- پاسخ‌های سریع محلی برای دستورهای روزمره — **۱۰۰ قابلیت آفلاین** (ریاضی، تبدیل واحد، سرگرمی، ماینکرفت و...) تقریباً بدون تاخیر
- تاریخچهٔ گفتگوها با عنوان خودکار

### 🎙️ صدا (گوی صوتی)
- **گوی صوتی زنده** با میکروفون — حرف بزن، جواب را می‌شنوی
- **Barge-in**: وسط صحنهٔ برنامه حرف بزن، سریع گوش می‌دهد
- تشخیص گفتار فارسی (vosk محلی + Web Speech) و **خودکار حرف زدن** بدون نیاز به کلیک
- صفحهٔ اختصاصی صدا با ورودی متنی هم برای تایپ

### 🧠 حافظهٔ هوشمند
- یادگیری خودکار نکات مهم از گفتگو + ثبت دستی «یادت باشه...»
- قوانین حریم خصوصی: شماره/رمز/اطلاعات حساس **هرگز ذخیره نمی‌شود**؛ فرمان «فراموش کن»
- جستجو، ویرایش و حذف خاطرات از صفحهٔ حافظه

### 🌐 هوش مصنوعی آنلاین رایگان
- مدل آنلاین رایگان **بدون کلید API** (Pollinations) + **مغز محلی** به‌عنوان پشتیبان خودکار
- اگر اینترنت قطع شود، خودکار به مغز آفلاین سوییچ می‌کند — گفتگو هرگز قطع نمی‌شود

## 💡 ذهن زنده — فکر کردن قبل از جواب

Peak می‌تواند **فکر کند**: قبل از هر پاسخ مهم، یک خط «فکر کوتاه» 💡 می‌نویسد (مثلاً «💡 دارم به سؤال فکر می‌کنم») و بعد جواب کامل را می‌دهد:

* همین خط فکر، **جملهٔ اول صدا** می‌شود → با **کمترین تأخیر ممکن** شروع به حرف زدن می‌کند
* فکرها در **حافظهٔ کوتاه‌مدت ذهن** می‌مانند تا گفتگو زنده و منسجم باشد
* برای سلام/خداحافظ/دستورهای کوتاه، بدون فکر و **فوری** جواب می‌دهد (تأخیر ≈ صفر)

## 🧠 مغز آفلاین — ۱۰۰ قابلیت داخلی (بدون اینترنت، بدون تأخیر)

حتی بدون هیچ اینترنت و کلیدی، **صد قابلیت** را فوری و محلی انجام می‌دهد (کافی است بگویید «کمک»):

| دسته | نمونه‌ها |
|---|---|
| 🧮 ریاضی | «۵+۵ چنده»، «۲۰ درصد ۱۵۰»، جذر، توان، فاکتوریل، تاس، شیر یا خط |
| 📏 تبدیل واحد | کیلومتر↔مایل، کیلو↔پوند، سانتی↔فارنهایت، متر↔فوت، مگ↔گیگ و... |
| 📅 تاریخ و زمان | روز هفته، سن، «تا ساعت ۵ چند مونده»، کبیسه، تایم‌استمپ، فصل |
| 🔤 ابزار متن | شمارش حروف/کلمات، برعکس، مورس، base64، آینه‌ای، حروف اول |
| 😊 سرگرمی | جوک، معما، شعر، ضرب‌المثل، زبان‌بند، گوی جادویی، انتخاب تصادفی، داستان |
| 🎮 ماینکرفت | رسپی‌ها، لایهٔ الماس، پورتال ندر، ابسیدین، ترفندها |
| 🔐 کاربردی | ساخت پسورد قوی، BMI، انعام، تخفیف، میانگین، مساحت، سهم هر نفر |
| 📚 فارسی | دیکشنری فارسی↔انگلیسی، ماه‌های شمسی/میلادی، اعداد، معنی ضرب‌المثل |
| 🧡 حال‌وهوش | صبح/شب بخیر، همدردی، انگیزه، تعریف، جملات انگیزشی |
| 🔬 دانش | سرعت نور، سیاره‌ها، فرمول آب، بزرگ‌ترین حیوان، عدد پی |

## 🧩 سیستم مودها — برای Peak مود اضافه کن!

صفحهٔ اختصاصی «مودها» — بدون دست زدن به هستهٔ برنامه، قابلیت سفارشی بساز:

* **نصب با یک کلیک** از گالری مودهای آماده
* **ساخت مود** از داخل برنامه (فرم ساده یا JSON پیشرفته)
* هر دستور مود می‌تواند: **پاسخ متنی فوری** | **دستور سرور (OP)** | **توانایی ماینکرفت**
* فایل JSON هم می‌توانی مستقیم داخل `data/mods/` بگذاری
* مودها فقط JSON ساخت‌یافته‌اند (کد اجرا نمی‌شود) → **امن، سبک، بدون فشار روی سیستم**
* روشن/خاموش و حذف هر مود — راهنمای کامل: [`docs/MODS-GUIDE.md`](docs/MODS-GUIDE.md)

## 📈 بهینه‌سازی — سبک برای سیستم شما

* فهرست بلند توانایی‌ها **فقط** وقتی گفتگو ماینکرفتی باشد به مدل می‌رود (کاهش مصرف توکن/رم)
* مودها با کش ۳ ثانیه‌ای و بدون اجرای کد — هزینهٔ تقریباً صفر
* پاسخ‌های محلی/مهارت‌ها/مودها **قبل از مدل** اجرا می‌شوند → بیشتر جواب‌ها بدون اینترنت و بدون تأخیر
* سقف حافظهٔ ساخت `--max-old-space-size=512` — مناسب رم‌های پایین

### 🎮 ربات ماینکرفت (Mineflayer)
- اتصال به سرورهای جاوا (آنلاین/کرکی) با دستورهای **فارسی و فینگیلیش**
- **۳۴۰ توانایی ماینکرفت**: احضار ۳۰+ ماب، ده‌ها آیتم/افسون/افکت، صاعقه، تلپورت، ساخت فوری، ماهیگیری، سواری، حفاری، کوله‌بار، زره، نبرد پیشرفته و...
- **سطح بازی**: مبتدی تا **خدا** 👑 — در سطح خدا خودش الماس/آهن استخراج می‌کند و از تیم دفاع می‌کند (دستش باز است)
- **شعاع اسکن تا ۱۰۰٬۰۰۰ بلوک** — با اختصاص رم بیشتر، شعاع بیشتر می‌شود
- **محافظت پلیسی**: دنبال‌کردن و دفاع از تو — هرگز به تو و دوستانت شلیک نمی‌کند
- **موشک**: دویدن + پرش ونیلا (بدون تقلب) | **اتوکلیک**: حملهٔ خودکار به نزدیک‌ترین دشمن
- **شخصیت‌ها**: vood pump (جنگ‌طلب)، مهربون، عادی — همه با احترام به لیست دوستان
- **حافظهٔ مکان**: جاهایی که بوده را یاد می‌کند؛ با «برگرد» به جای قبلی برمی‌گردد
- **اسکن محیط تا ۱۰۰۰ بلوک**: خصم‌ها، بازیکنان، خطرها (گدازه/آتش/TNT)
- دوستان را یک‌به‌یک اضافه کن؛ سرور کرکی با رمز `@1988@1988`

### ⚡ تست API هوش مصنوعی
- هر API را تست کن و **بگو از کدوم هوش مصنوعی است** + تاخیر و نام مدل
- فهرست آمادهٔ بهترین‌ها (اولویت: ماینکرفت‌باز قوی + گفتار خوب + تاخیر کم)
- با فرمان صوتی «تست ای پی ای» هم کار می‌کند

### 🖥️ برنامهٔ دسکتاپ مستقل
- نصب‌کننده (Setup) + نسخهٔ Portable — بدون نیاز به مرورگر
- Node داخل بسته — **بدون نیاز به نصب Node.js**
- ۶ صفحهٔ کامل: چت، صدا، ماینکرفت، حافظه، تنظیمات، دانلودها

## 📥 نصب سریع

1. از بخش **Releases** همین ریپو، فایل `Peak-Setup-Latest.exe` را دانلود کن (یا `Peak-Portable-Latest.exe` برای اجرای بدون نصب)
2. اجرا کن — تمام ✅ (Node.js لازم نیست)
3. اگر آنتی‌ویروس هشدار داد: فایل را Unblock کن (برنامه جدید و بدون امضا است)

**ساخت از سورس (اختیاری):** `npm ci` ← `npm run build` ← `npm run dist:win` — یا همان Push به گیت‌هاب و اجرای **Actions** که خودش EXE را می‌سازد.

**عیب‌یابی:** اگر برنامه باز نشد، فایل `peak-log.txt` در `AppData\Roaming\Peak\data` علت دقیق را نشان می‌دهد.
